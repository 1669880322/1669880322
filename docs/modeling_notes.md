# Modeling Notes (v1)

## 1. 为什么仅使用二阶主方程

本版本聚焦结构阻尼参数反演，因此将训练主方程限定为二阶单模态等效形式：
\[
\ddot q_2 + c_2 \dot q_2 + k_2 q_2 + \kappa k_2 q_2^3 = 0
\]
这样可降低参数耦合复杂度，便于构建稳定可复现实验基线。

## 2. 为什么输入是整段振幅序列

目标是逆识别参数，不是解算状态轨迹映射。网络输入 `amplitude_sequence`（整个时间窗），输出单标量 `c_struct_hat`，匹配工程中的“已采集完整振动记录 -> 识别结构参数”流程。

## 3. 为什么默认辨识结构阻尼

- 阻尼直接影响衰减包络与稳态振幅分布；
- 相比流体参数联合反演，病态性较低；
- 更适合作为“参数+物理约束+可微求解”闭环第一版。

## 4. 参数硬编码组织

所有无量纲参数集中在 `config.py`，作为 v1 标准测试配置：
`alpha, Omega_tilde, phi1, phi2, lambda_, beta, u, u1, gamma, g0, A, omega1, kappa, u0_fixed` 等。

> 说明：这些是第一版标准化测试参数，后续应替换为更严格的物理换算值/实验标定值。

## 5. 为什么保留 c1/c11/c22/g1/k1 但主训练只用 c2/k2

完整降阶推导背景需要这些系数保持可追溯。虽然主任务只依赖二阶主方程的 `c2,k2`，但项目仍显式保留并进行 sanity check，保证模型扩展到更完整耦合框架时无需重构底层系数组装。

## 6. 1.5–5 um 振幅范围工程化实现

先由动力学方程积分得到 `q2(t)`，再构造
\[
a(t)=\text{scale\_um}\sqrt{q_2(t)^2+\varepsilon}
\]
通过统一 `scale_um` 调整量纲范围（以数据整体统计量 p95 为准）进入 1.5–5 um 工程窗口，不对单样本施加形状扭曲。

## 7. 为什么平滑振幅算子而非 abs(q2)

`abs(q2)` 在 0 附近不可导，可能导致梯度不稳定。采用 `sqrt(q2^2+eps_amp)` 可保持近似绝对值效果，同时改善反向传播稳定性。

## 8. 固定初值策略与后续扩展

v1 采用固定初值：
- `q2(0)=q20_fixed`
- `q2_dot(0)=q2d0_fixed`

原因：减少参数-初值耦合病态，先稳定识别 `c_struct`。

后续扩展到“参数 + 初值联合反演”的工程方案：
1. 在模型头部增加 `q20_hat, q2d0_hat` 输出；
2. 在损失函数中提高 `Lic` 权重并增加先验约束；
3. 引入多窗口/多工况联合训练降低不可辨识性。

## 9. 符号歧义工程化解释

1. 文中 `nu` 统一工程映射为代码变量 `u`。
2. `lambda` 为 Python 关键字，映射为 `lambda_`。
3. `Omega_tilde` 直接保留为代码字段 `Omega_tilde`。
4. 系数函数支持 `t` 为 `[T]` 或 `[B,T]`，并在内部广播到批维度。
5. `c_struct_hat` 是网络输出（每样本一个标量），训练中按 `[c_min,c_max]` 执行 clamp。

## 10. 与经典 PINN 教学范式的差异

- 经典示例：输入时间点、输出状态；
- 本项目：输入完整观测序列、输出参数；
- 经典示例：直接拟合状态；
- 本项目：通过可微积分器重构状态并施加物理残差约束，实现逆问题闭环。
